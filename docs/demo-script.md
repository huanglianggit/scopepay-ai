# Three-minute demo plan

Do not record the final competition video until a real model and a real PayPal Sandbox transaction have been verified. Describe the environment accurately; a walkthrough-rule result must never be presented as model inference.

## 0:00–0:20 — Problem

“A client says: ‘Could we also add a Chinese version and appointment booking?’ For a freelancer, that small message can change the price, delivery date and expectations. ScopePay helps both sides make that change explicit.”

## 0:20–0:55 — Source-backed analysis

Show the original one-page English website agreement. Paste the new message. Run the configured model. Expand source evidence and show how it references actual clauses and request passages. Show the ambiguous booking deliverable.

## 0:55–1:25 — Human review

Record the clarification: embed an existing scheduling service, not a custom booking/payment backend. Adjust the price and due date. Explain that fees are studio-controlled. Save the draft and publish the locked version.

## 1:25–2:10 — Client confirmation and PayPal

Open the client page. Show itemized additions and the delivery date. Confirm the version as a synthetic test client. Enter PayPal Sandbox checkout using the generated buyer account. Complete the test payment and return. Show the verified capture in ScopePay and optionally in the Sandbox seller activity.

## 2:10–2:40 — Evidence and failure handling

Refresh the studio. Show the confirmed status and activity. Export the record. Briefly show that an accepted version cannot be changed and that a revision replaces an unanswered quote instead of silently changing it.

Optional supporting shot: in **Scope & fees**, show the confirmed addition and the separate Sandbox paid balance, then export the project summary. If demonstrating a client-requested revision instead, show **What changed since vN** with a removed item and fee difference. Keep within the same time budget; do not add both walkthroughs at the expense of the actual PayPal flow.

## 2:40–2:55 — Value and scope

“ScopePay connects the client's actual request, the agreed version, and its payment. Both sides can see what changed and what was paid for.”

Keep total footage below three minutes. Use English narration or subtitles, synthetic client content, and cleared visual/audio assets. Do not show real credentials or private client links.
